How the forecast is built

  • Hs (wave model): hourly significant wave height from the Open-Meteo marine API, which blends NOAA GFS-Wave, DWD EWAM and ECMWF WAM output for the site's grid cell ().
  • Hs (blended): within each NWS Boston coastal-waters forecast period for zone ANZ255 (out to 25 nm south of Martha's Vineyard and Nantucket), the model Hs is averaged 50/50 with the midpoint of the NWS "seas" range. NWS seas are reported as significant wave height. NWS issued: .
  • Hmax: uses Rayleigh statistics over a 3-hour sea state, with N = 10 800 s ÷ Tm waves (Tm is the model's mean period). Most probable Hmax = Hs·√(ln N / 2), which is about 1.9–2.0 × Hs here. The 90% bound = Hs·√(ln(N/0.105) / 2), about 2.1 × Hs.
  • CTV limit: hours with blended Hs ≤ m are counted as workable for crew-transfer vessels. This is a typical planning threshold, not a project-specific limit.

  • Daily refresh: a scheduled task pulls fresh model data, the NWS forecast and the buoy reading each morning, then republishes this page.
